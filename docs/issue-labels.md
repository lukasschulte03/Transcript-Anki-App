# Issue-etiketter

Varje issue ska ha exakt minst en etikett för prioritet och ett område.

- `prioritet: hög` – blockerar kärnflödet eller bör göras härnäst.
- `prioritet: medium` – viktigt efter kärnflödet.
- `prioritet: låg` – förbättring som kan vänta.
- `prioritet: senare` – medvetet uppskjutet arbete.

Områdena är `område: anki-ai`, `område: data`, `område: ljud`,
`område: synk`, `område: transkribering` och `område: ui`.

Issue-formen sätter säkra standardetiketter. GitHub Actions fyller även i
saknade etiketter för issues som skapas från CLI, API eller en länk. En
automatiskt vald område-etikett är en startpunkt och kan justeras när issue
triageras.
